# Animator / Sign Reviewer Brief

## Goal
Create clear, natural, reviewable avatar actions for selected Grade 10 Mathematics key terms.

## Motion requirements
- Use the same Louise skeleton for every clip.
- Neutral pose at start and end.
- No shoulder shrugging.
- Elbows should follow the validated reference and never collapse through the torso.
- Avoid hand/body intersections.
- Keep signing inside the camera-readable signing space.
- Fingers must be readable from the default camera.
- Prefer 30 FPS.
- Typical lexical clip length: 1.0–2.5 seconds unless the reference requires longer.
- No facial/non-manual claim unless it has been intentionally authored and validated.

## Validation
For each lexical clip record:
- reviewer name/role;
- reference source;
- review date;
- accepted / revise;
- notes on handshape, orientation, location, movement, handedness, and non-manual markers.

## Technical acceptance
- Action name exactly equals the manifest ID.
- No root translation unless intentional.
- Same armature/bone names.
- No helper objects exported.
- First and last frames match the shared neutral pose.
