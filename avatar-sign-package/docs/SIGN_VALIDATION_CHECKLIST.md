# Sign Validation Checklist

For each lexical sign, do not approve based only on visual attractiveness.

Check:
1. Handshape
2. Palm orientation
3. Hand location
4. Movement path
5. Movement direction
6. One-hand / two-hand use
7. Dominant hand
8. Timing
9. Body contact / spatial relationship
10. Non-manual markers where relevant
11. Mathematical meaning in the lesson context
12. Readability on the final avatar/camera

Statuses:
- `needs_validation`
- `validated`
- `technical_only` (for IDLE or non-lexical technical clips)
