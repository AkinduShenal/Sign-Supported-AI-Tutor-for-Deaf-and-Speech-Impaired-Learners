# Linear Equation Avatar Animation Catalog

This package contains 22 animation clips embedded in one Louise GLB.

## Lesson concept clips
- IDLE — shared neutral start/end pose
- EQUATION — symmetric equation concept gesture
- BALANCE — balance concept gesture
- BOTH_SIDES — both hands move outward symmetrically
- VARIABLE — dominant index identifies the unknown/variable
- ADDITION — combining/inward operation gesture
- SUBTRACTION — removing/outward operation gesture
- MULTIPLICATION — two index gestures converge/cross
- DIVISION — division/separation gesture
- SUBSTITUTION — replacement/insertion gesture
- SOLVE — closed-to-open solution process gesture
- ANSWER — presentation/result gesture

## Number clips
NUMBER_0 through NUMBER_9. Numbers 0-5 use the dominant hand; 6-9 use five on the non-dominant hand plus 1-4 on the dominant hand.

## Technical pose rule
Main active poses were generated using direct FK rotation channels. Elbows are solved outward from the shoulder line rather than using Blender pole-target IK.

## Research wording
These are prototype educational avatar gestures. They are not linguistically validated Sri Lankan Sign Language clips. Do not describe them as validated SLSL without human sign-language review.
